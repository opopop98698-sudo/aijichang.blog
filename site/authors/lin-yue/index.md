# 林越 (Lin Yue) - 首席网络架构师与评测作者档案

> “网络协议没有玄学，每一帧卡顿与阻断的背后，都是路由拓扑、出口识别与风险策略的具体博弈。”

---

## 个人专业经历与技术背景

**林越** 是 aijichang.blog 的创始人之一兼首席技术评测工程师。毕业于计算机科学与技术专业，专注于计算机网络体系结构与分布式系统路由研究。

在加入跨境网络选购指南项目之前，林越曾先后在跨国软件企业与全球云计算服务集成商担任高级网络工程师与 SRE 架构师，累计深度管理过亚太区超过 40G 的跨国专线带宽（IEPL/IPLC），深度熟悉 BGP 动态多线调度、Anycast 节点分发以及 TLS 1.3、VLESS、Shadowsocks-2022、Sing-box 的内部实现机制。

### 核心专长领域
- **专线拓扑与延迟优化**：精通电信 CN2 GIA、联通 9929、移动 CMIN2 等精品公网链路与内网专线的真实抗压边界；
- **AI 任务长连接维护**：针对 OpenAI、Claude、Gemini 的 SSE（Server-Sent Events）流式数据传输特性，设计并落地了一套防 TCP RST 与长连接心跳维活测评标准；
- **流媒体 CDN 调度与原生出口核验**：针对 Netflix 4K、Disney+ 与 YouTube Premium，制定了严格基于 MaxMind、IPinfo 数据库与平台本地住宅 IP 风险分（Fraud Score）的四层判别法。

## 严正声明与评测道德约束

1. **零特权测试**：林越在执行所有测试时，坚决拒绝服务商开通的特权测试通道或白名单 IP 段，所有结论均基于线上在售真实套餐；
2. **客观事实至上**：即使面对合作推广品牌，对于晚高峰丢包、流媒体证书报错或虚标速率等问题，依然在评测中如实归档并保留存证，绝不做选择性隐瞒；
3. **欢迎同行审阅**：所有测试方法均公开透明，欢迎网络工程师与安全研究员复核验证并提交[勘误建议](/corrections/)。
